# HCQ Rest API

RESTful API based on Express JS and Node JS v20 for Halaqoh Cinta Qur'an Halaqoh System.

## Environment Variables

Configure the required Environtment Variables.

```env
PORT = 8080

DB_HOST = your_db_host_ip
DB_USER = your_db_user
DB_PASSWORD = your_db_password
DB_DATABASE = your_database_name

TOKEN_SECRET = anything_that_is_hard_to_guess
```
